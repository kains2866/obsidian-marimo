## 首次远程 CI 发现的环境遗漏

远程格式化测试返回 HTTP 500；在只安装 marimo 的全新虚拟环境中复现相同失败。官方格式化端点要求额外安装 Ruff，本机已有 Ruff 0.17.3，因此原有本地测试通过。已将 Ruff 0.17.3 加入 requirements-dev.txt，并同步中英文手动安装命令；未跳过测试、未放宽断言、未增加自动安装行为。补齐依赖后，同一个全新虚拟环境的 64 项测试全部通过。远程最终结果以修复后的 CI 为准。
