# 0.0.1

Initial release preparation for MarimoNotebook, a native marimo notebook editor for Obsidian desktop.

- Edit cells and Markdown with Obsidian's native controls and theme. Add, move, split, disable and remove cells.
- Connect explicitly to a local marimo 0.25.2 / Python 3.12 environment for reactive execution, interactive widgets, tables, charts and input prompts.
- Navigate headings, variables and cell dependencies in native side panels. Save standard marimo `.py` files and retain recovery drafts for unsaved changes.
- Optionally configure an OpenAI-compatible AI endpoint for generation, refactoring, chat and inline completion.
- Bundle chart engines locally; default new installations to manual connection, preserving existing explicit auto-connect settings.

This is an early implementation with a fixed runtime version and partial widget coverage. See the README for installation, privacy disclosures and current boundaries. Windows/Linux GUI behavior remains unverified on real devices.
